下面接口以你现有文档风格为参照（GET + Query 参数 + JSON 返回）。

### 1. 获取知识点掌握度趋势（绿色框2）

**接口地址：**  
`GET /api/knowledge/mastery-trend`

**功能说明：**  
返回某个学生在一段时间内，若干关键知识点的掌握度变化趋势，用于绿色框 2 折线图展示。

#### 请求参数

| 参数名        | 类型   | 必填 | 说明                                                         |
| ------------- | ------ | ---- | ------------------------------------------------------------ |
| student_id    | string | 是   | 学生 ID                                                      |
| class_name    | string | 否   | 班级名称，用于计算班级平均（如需要做对比可扩展）             |
| start_month   | string | 否   | 起始月份，格式：`YYYY-MM`，默认按数据中最早月份              |
| end_month     | string | 否   | 结束月份，格式：`YYYY-MM`，默认按数据中最晚月份              |
| top_k         | int    | 否   | 返回前 K 个“关键知识点”（如按学习重要性/掌握度波动度等排序），默认 4 |
| knowledge_ids | array  | 否   | 指定一组知识点 ID 列表，若提供则优先返回这几项，而不是自动 Top K |

> 说明：  
> - 若同时提供 `knowledge_ids` 和 `top_k`，优先使用 `knowledge_ids`。  
> - `start_month` / `end_month` 不传则取该学生在数据中的完整时间跨度。

#### 响应示例

```json
{
  "student": {
    "id": "8b6d1125760bd3939b6e",
    "name": "张三",
    "class_name": "J23517"
  },
  "mastery_trend": {
    "r8S3g": {
      "knowledge_id": "r8S3g",
      "knowledge_name": "程序控制",
      "series": [
        { "month": "2023-09", "mastery": 0.45, "mastery_percentage": 45.0 },
        { "month": "2023-10", "mastery": 0.58, "mastery_percentage": 58.0 },
        { "month": "2023-11", "mastery": 0.62, "mastery_percentage": 62.0 },
        { "month": "2023-12", "mastery": 0.68, "mastery_percentage": 68.0 }
      ]
    },
    "m3D1v": {
      "knowledge_id": "m3D1v",
      "knowledge_name": "数据结构",
      "series": [
        { "month": "2023-09", "mastery": 0.70, "mastery_percentage": 70.0 },
        { "month": "2023-10", "mastery": 0.75, "mastery_percentage": 75.0 },
        { "month": "2023-11", "mastery": 0.80, "mastery_percentage": 80.0 },
        { "month": "2023-12", "mastery": 0.86, "mastery_percentage": 86.0 }
      ]
    }
  },
  "meta": {
    "start_month": "2023-09",
    "end_month": "2023-12",
    "selected_knowledge_ids": ["r8S3g", "m3D1v"],

  }
}
```

#### 字段说明

- **student**
  - `id`: 学生 ID  
  - `name`: 学生姓名（可选）  
  - `class_name`: 班级名称（可选）

- **mastery_trend**（对象，key 为 `knowledge_id`）
  - `knowledge_id`: 知识点 ID  
  - `knowledge_name`: 知识点名称  
  - `series`: 数组，按时间排序的掌握度序列
    - `month`: 月份，格式 `YYYY-MM`
    - `mastery`: 掌握度（0–1）
    - `mastery_percentage`: 掌握度百分比（0–100）

- **meta**
  - `start_month` / `end_month`: 实际统计使用的时间范围  
  - `selected_knowledge_ids`: 当前返回的知识点 ID 列表  
  - `total_available_knowledge`: 该学生在时间范围内涉及的总知识点数
